# CLEO Redux

Tested: 1.5.1 (x86). [Download](https://github.com/cleolibrary/CLEO-Redux/releases)

## Install

VCUnlock has to load before CLEO Redux. Otherwise VCUnlock turns its frame rate fix off and the game stays at 30 fps.

1. Install VCUnlock as in the [README](../README.md#install). `VCUnlock.asi` stays in the game folder.
2. Make a `scripts` folder in the game folder.
3. Put `cleo_redux.asi` and the `CLEO` folder into `scripts`. CLEO Redux then uses `scripts\CLEO` for its scripts and plugins.

## Steam and Japanese versions

CLEO Redux crashes these by itself, also without VCUnlock. There is no fix.
